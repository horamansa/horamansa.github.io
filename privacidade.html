Política de privacidade

Última atualização: 04/10/2026

Quem somos

Hora Mansa é um canal no YouTube (@horamansa) de paisagens sonoras. Contato: yorgosnc1@gmail.com.

O sistema do canal

O canal usa um sistema próprio, de uso exclusivo do responsável pelo canal, que se conecta aos Serviços de API do YouTube (YouTube API Services) para enviar os vídeos do próprio canal, definir miniaturas e playlists e consultar as estatísticas do próprio canal. O sistema não é oferecido a outras pessoas e não coleta dados de espectadores.

Serviços de API do YouTube

Este sistema usa os Serviços de API do YouTube. Ao usá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Dados acessados

Somente dados do próprio canal Hora Mansa, autorizados pelo responsável pelo canal:

  • identificação do canal (nome e identificador);
  • informações dos vídeos do canal (títulos, descrições, miniaturas, status de publicação);
  • estatísticas agregadas do canal (visualizações, tempo de exibição, inscritos).

Nenhum dado pessoal de espectadores é coletado.

Uso e armazenamento

Os dados são usados apenas para publicar e organizar os episódios e para avaliar o desempenho do canal. Ficam armazenados de forma privada, em computadores e servidores do responsável pelo canal, com acesso protegido. Não são vendidos nem compartilhados com terceiros.

Retenção e exclusão

Os dados obtidos pela API são atualizados periodicamente e apagados quando deixam de ser necessários. Se o acesso for revogado, esses dados são apagados em até 30 dias.

Como revogar o acesso

O acesso do sistema à conta pode ser revogado a qualquer momento na página de permissões da Conta do Google: myaccount.google.com/permissions.

Este site

Este site não usa cookies, ferramentas de análise nem qualquer tipo de rastreamento.

Alterações

Esta política pode ser atualizada. A data no início da página indica a versão em vigor.

Privacy policy (English)

Last updated: 2026-10-04

Who we are

Hora Mansa is a YouTube channel (@horamansa) of ambient soundscapes. Contact: yorgosnc1@gmail.com.

The channel's system

The channel uses its own internal system, used only by the channel owner, which connects to YouTube API Services to upload the channel's own videos, set thumbnails and playlists, and read the channel's own statistics. The system is not offered to anyone else and does not collect any viewer data.

YouTube API Services

This system uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service; see also the Google Privacy Policy.

Data accessed

Only data of the Hora Mansa channel itself, authorised by the channel owner: channel identity (name and id), information about the channel's videos (titles, descriptions, thumbnails, publishing status) and aggregated channel statistics (views, watch time, subscribers). No personal data of viewers is collected.

Use, storage and sharing

The data is used only to publish and organise episodes and to evaluate the channel's performance. It is stored privately on computers and servers controlled by the channel owner, with protected access. It is never sold or shared with third parties.

Retention and deletion

Data obtained through the API is refreshed periodically and deleted when no longer needed. If access is revoked, that data is deleted within 30 days.

How to revoke access

Access can be revoked at any time on the Google Account permissions page: myaccount.google.com/permissions.

This website

This website uses no cookies, analytics or tracking of any kind.
